Supported keywords include type, enum, const, required, properties, additionalProperties, items, pattern, lengths, numeric bounds, uniqueItems and property counts. This is not a full JSON Schema implementation.

How to validate JSON with a schema

  1. Paste your JSON data on the left.
  2. Paste the expected schema on the right.
  3. Validate and fix each reported path such as $.user.email.

Use this page for common local checks and fast debugging.

Compatibility limitation

This lightweight validator does not resolve $ref or remote schemas, does not implement allOf, anyOf, oneOf, not, or the full format vocabulary. Complex schemas may produce incomplete results.

For production-critical validation, use the same complete schema engine as your application.

Schema validator FAQ

What does JSON Schema do?

It defines the expected shape of JSON, including types, required fields and values or lengths that are allowed.

Does schema validation upload my data?

No, this page validates with browser-side JavaScript and does not send JSON to a validation server.
