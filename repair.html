Only predictable syntax issues are corrected. Missing values or braces are not guessed.

What can be fixed?

This tool tries smart quotes, single-quoted strings, comments outside strings, unquoted property names, a leading byte-order mark and trailing commas. Valid input is formatted.

How to use

  1. Paste JSON-like text or load the example.
  2. Repair it and inspect the change report.
  3. Copy or download the result only after reviewing it.

What it will not do

It will not invent missing values or braces. If a correction is ambiguous, it reports a parser error instead of claiming success.

Privacy and safety

Processing happens in this browser tab. Successful parsing is not proof that data is trustworthy or valid for your application's business rules.

Use the JSON Schema Validator for additional structural checks.

JSON repair FAQ

Does repair always recover broken JSON?

No. Some syntax errors are ambiguous; this tool handles common cases and reports failures.

Does it upload my data?

No repair request is sent by this page. The text is processed by local JavaScript.
