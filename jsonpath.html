JSONPath Query Tool

Query nested JSON objects and arrays with a lightweight JSONPath-style selector. Return matching values and their paths without uploading the data.

Supports $, .property, ['property'], ["property"], [index] and .* or [*]. Recursive descent and filters are not supported.

JSONPath query examples

  • $.users[0].name selects the first user's name.
  • $.users[*].name selects the name property for every user.
  • $.metadata.* selects every direct metadata value.
  • $['display-name'] selects a property with a hyphen.
Supported subset

Recursive descent, predicates and filters, slices, functions and every option in the full JSONPath specification are not implemented. Unsupported expressions return an error rather than a guessed result.

JSONPath FAQ

Does a query modify JSON?

No. It selects and reports values without changing the input.

Is query execution local?

Yes. Parsing and evaluation run inside your browser.
