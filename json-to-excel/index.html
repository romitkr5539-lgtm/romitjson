Convert JSON to Excel (XLSX)

JSON is a common format for API responses and application data, while Excel is built for reviewing information in rows and columns. This JSON to Excel converter turns a JSON object or an array of records into a previewable worksheet and a downloadable .xlsx workbook. It is useful for checking exports, sharing records with spreadsheet users, or preparing a simple table for further analysis.

Paste valid JSON or open a JSON file, choose whether to include headers and flatten nested objects, set the worksheet and file names, then select Prepare workbook. Review the row and column preview before downloading. The conversion runs in your browser; your JSON is not uploaded for workbook creation.

How to Convert JSON to an Excel Workbook

  1. Paste JSON into the input panel or select Open JSON to load a file.
  2. Choose whether to include a header row and flatten nested objects.
  3. Leave Spreadsheet-safe values on for its default array and formula-like string handling, or turn it off to keep arrays as JSON text.
  4. Enter a worksheet name and the base file name if you want to change the defaults.
  5. Select Prepare workbook and inspect the preview, row count, and column count.
  6. Select Download to save an .xlsx file, or Copy as TSV to paste the preview into a spreadsheet.

The input must be valid JSON. If it will not parse, check it with the JSON Validator first.

Example: Nested JSON in Excel Columns

With nested-object flattening enabled, an object such as customer becomes separate columns. The default spreadsheet-safe setting joins array items in one cell:

Input JSON

[
  {"orderId":"00073","status":"open","customer":{"name":"Mina Patel","city":"Pune"},"tags":["priority","email"]},
  {"orderId":"00074","status":"closed","customer":{"name":"Luis Chen","city":"Austin"},"tags":["refund"]}
]

Worksheet preview

orderId | status | customer.name | customer.city | tags
00073   | open   | Mina Patel    | Pune          | priority; email
00074   | closed | Luis Chen     | Austin        | refund

The dotted headers show where nested values came from. The preview also makes it easier to catch a missing field or an unexpected column before saving the workbook.

How the Converter Maps JSON to a Worksheet

Rows and headers

An array of objects is the best fit for a spreadsheet: each object becomes one row, and the converter gathers columns from the keys it finds across those objects. If a record is missing a key, that cell is blank. A single object becomes one row. The Include header row option controls whether property names appear before the data.

Nested objects and arrays

When Flatten nested objects is on, nested object paths become headers such as customer.city. Turn it off to keep a nested object as JSON text in one cell. Arrays do not expand into extra rows, columns, or worksheets. With Spreadsheet-safe values on, array items are joined in one cell with a semicolon and a space. Turn that option off to keep an array in JSON notation instead.

If an API wraps a record list inside a property—for example, {"data":[...]} or {"results":[...]}—this converter does not automatically select that inner list. It treats the top-level object as one record. For a clean table, extract the array and convert that array of records.

Value types

Cell values are written as text, including numbers and booleans. This helps keep identifiers such as 00073 intact, but a numeric-looking cell may not work directly in Excel formulas or numeric sorting. Convert the relevant column to numbers in Excel if you need calculations. The workbook is a tabular export, not a lossless copy of JSON types and nesting.

Worksheet, File Name, and Spreadsheet-Safe Settings

  • Worksheet name: The default is Sheet1. You can enter up to 31 characters; use a valid Excel sheet name.
  • File name: Set the base name before downloading. The converter creates an .xlsx file and normalizes unsupported filename characters.
  • Spreadsheet-safe values: This option is enabled by default. It joins arrays with semicolons and prefixes strings beginning with whitespace or =, +, -, or @ with an apostrophe. This changes some exported text and is a precaution, not a guarantee about how every spreadsheet handles the value.
  • Copy as TSV: Copies the preview as tab-separated text, which is handy for pasting directly into an existing spreadsheet.

This tool creates one worksheet of plain tabular data. It does not create multiple sheets from separate JSON collections or add Excel formulas, charts, or cell styling. If the JSON contains unrelated tables, prepare each table separately or use a workflow designed for multi-sheet workbooks.

Frequently Asked Questions

Can I convert a single JSON object to Excel?

Yes. A standalone object is converted as one row. With the header option enabled, its property names appear above the row.

Can I convert a JSON array to Excel?

Yes. An array of objects is the recommended input: every object becomes a row, and keys found across the records become columns.

Does the converter create multiple worksheets?

No. Each conversion creates one worksheet. A JSON object containing several arrays is treated as one record rather than as instructions to create separate sheets.

Will Excel keep numbers as numbers?

No. This converter writes cell values as text. That preserves text identifiers such as postal codes with leading zeros, but numeric columns may need to be converted to numbers in Excel before using formulas or numeric sorting.

Does the converter upload my JSON?

No. JSON parsing and workbook creation happen in your browser, and the data is not uploaded for conversion. See the RomitJSON privacy information for more about the site.

Can I paste the result into a spreadsheet without downloading?

Yes. Choose Copy as TSV, then paste into Excel or another spreadsheet. The copied content includes the header row only when that option is enabled.
