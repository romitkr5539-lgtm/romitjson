How JSON size analysis works

The tool parses the input and walks the data structure to count value types, nesting depth, object keys and array items. It measures the source using UTF-8 and estimates pretty-printed and minified output sizes.

Find the largest fields

The table sorts top-level properties or array entries by serialized size. Use the JSON Viewer to inspect deeper structure.

Size is not transfer size

HTTP compression such as gzip or Brotli can reduce bytes sent over a network. These results measure the JSON text, not protocol overhead or compressed payload size.

Your input remains in the browser; no JSON is sent to an analysis service.

JSON analyzer FAQ

Why is pretty JSON larger?

Indentation and line breaks add whitespace for readability. Minification removes unnecessary whitespace without changing parsed values.

Does this measure gzip size?

No. It measures uncompressed UTF-8 size and estimates representations of the JSON text.
