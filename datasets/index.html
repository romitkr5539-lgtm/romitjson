QUICK GUIDE

How to use and edit these datasets

Use a sample as a starting point: inspect its structure, copy or download the original, then edit your own copy in the browser. Changes you make are yours to validate and export; they do not change the library's published sample.

01

Find a useful sample

Search by a dataset name, filename, topic, or description, or choose a category. Select a card to open its detail page. Check the record count and the explanation before using it.

02

Inspect, copy, or download

Read the formatted preview on the detail page. Choose Copy JSON to put the complete source text on your clipboard, or Download JSON to save the named .json file. Open it in the Formatter or Viewer to inspect its structure.

03

Edit your own copy

Open the JSON Editor. Paste the copied JSON into the editor, or choose Open JSON to load the downloaded file. Edit values in the text area; use Tree view if you prefer exploring the structure visually.

04

Validate and save the result

Use Validate JSON to check syntax and Format to indent the edited data. When it is valid, use Copy or Download in the editor to keep your version. Downloaded edits do not overwrite the original dataset.

Testing edge cases? Use Null Values to check explicit null separately from zero or an empty array, Empty Array to test valid zero-result responses, Deeply Nested JSON to exercise long paths, and Large Record Array for scrolling and pagination checks. That sample has 30 records, so it is a functional test fixture rather than a large-scale performance benchmark.

Every dataset is fictional, static, and served from RomitJSON. Sample content is not production data. Use the JSON Formatter or JSON Viewer to explore a dataset after opening its page.
